# Plumbline motion site

Static HTML + CSS + GSAP 3.13 (ScrollTrigger, SplitText), vendored in `vendor/`. No build step.
Metaphor: a plumb line. Crooked evidence settles true; the draw opens. Motion is a damped pendulum.

- `index.html` sections: hero (settling stack), devnet marquee, before/after (scrubbed), pinned three-roots story,
  bento, coverage toy (1.15x floor), stats, FAQ, pilot form (POST `/api/lead`), footer.
- Copy and numbers come from `SUBMISSION-FACTS.md` / `SUBMIT-NOW.md`. Pricing is a marked placeholder.
- Serve locally: `python3 -m http.server` in this folder.
